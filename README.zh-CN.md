# 番剧信息（bangumi）

> <sub>本文档由 Anthropic 的 Claude Fable 5.2 生成。</sub>

这是 Miyu 的一个脚本软件包，提供一件工具 `bangumi`，用来查询番组计划（bgm.tv）。

- **放送表**：查询今天、明天、某一天或者整周播出哪些番剧，按评分排序（评分人数不到 50 的排在后面）。
- **搜索**：按名字搜索动画、书籍、游戏、音乐和三次元条目。
- **条目**：给出评分、排名、标签和简介；对于动画，还会给出播到了第几集、下一集哪天播出。
- **剧集表**：给出 `limit` 时，只列出到下一集为止的最近 N 集，所以长篇（例如上千集的海贼王）也不会刷屏；还没有开播的番剧列出开头的 N 集。

## 参数

这件工具接受下面这些参数：

| 参数 | 说明 |
|---|---|
| `action` | `calendar`、`search`、`subject`、`episodes`；不填写时，如果有 `query` 就是 `subject`，没有就是 `calendar` |
| `query` | 条目名（中文译名或者原名），或者 bgm.tv 的条目 id；按名字查询时取最匹配的一个，其余的列在后面 |
| `weekday` | 用于放送表：`today`（默认）、`tomorrow`、`week`、`mon`–`sun`、`1`–`7`、`周一`–`周日` |
| `type` | `anime`（默认）、`book`、`game`、`music`、`real` |
| `limit` | 放送表里每天列出的部数、搜索结果的条数（默认 8，最多 25）、剧集表列出的集数 |
| `format` | `md`（默认）或者 `json` |

## 依赖与注意

这一节说明工具依赖什么，以及缓存和日期是怎样处理的。

- 工具只使用 Python 标准库，通过 `api.bgm.tv` 的公开接口查询，不需要登录。
- 放送表每天只获取一次，缓存在 `MIYU_CACHE_DIR` 里；如果没有缓存目录，就每次重新获取。
- 「今天」按运行这个工具的机器的本地日期计算。

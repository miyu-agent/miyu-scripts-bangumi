# Bangumi (bangumi)

> <sub>This document was generated by Anthropic's Claude Fable 5.2.</sub>

This is a script package for Miyu. It provides one tool, `bangumi`, which looks things up on Bangumi (bgm.tv).

- **Airing schedule**: which shows air today, tomorrow, on a given day or over the whole week, sorted by score (shows rated by fewer than 50 people are placed last).
- **Search**: search anime, books, games, music and live-action subjects by name.
- **Subject**: the score, rank, tags and summary; for anime, it also gives the latest aired episode and the date the next episode airs.
- **Episode list**: when `limit` is given, only the latest N episodes up to the next one are listed, so even a long series (such as One Piece, with over a thousand episodes) does not flood the output; for a show that has not started airing, the first N episodes are listed.

## Parameters

The tool takes the following parameters:

| Parameter | Description |
|---|---|
| `action` | `calendar`, `search`, `subject`, `episodes`; when it is left out, it is `subject` if `query` is given and `calendar` otherwise |
| `query` | A subject name (the Chinese title or the original title), or a bgm.tv subject id; a name opens the best match and lists the others after it |
| `weekday` | For the airing schedule: `today` (default), `tomorrow`, `week`, `mon`–`sun`, `1`–`7`, `周一`–`周日` |
| `type` | `anime` (default), `book`, `game`, `music`, `real` |
| `limit` | The number of shows per day in the airing schedule, the number of search results (default 8, at most 25), or the number of episodes in the episode list |
| `format` | `md` (default) or `json` |

## Dependencies and notes

This section explains what the tool depends on and how it handles caching and dates.

- The tool uses only the Python standard library and queries the public API at `api.bgm.tv`; no login is needed.
- The airing schedule is fetched only once a day and cached in `MIYU_CACHE_DIR`; if there is no cache folder, it is fetched fresh every time.
- "Today" is based on the local date of the machine that runs the tool.
